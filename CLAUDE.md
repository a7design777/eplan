# Правила проєкту eplan

Ці правила обов'язкові. Перечитувати перед кожною зміною коду.
План і структура — у [PLAN.md](PLAN.md); після завершення етапу оновлювати там статус.

## Оточення

- Node встановлено вручну в `~/.local/node` (Intel x64, v24.19.0). Homebrew на машині немає.
- У кожній сесії bash PATH треба виставляти явно: `export PATH="$HOME/.local/node/bin:$PATH"`.
- Пакетний менеджер — `npm`. Не додавати yarn/pnpm.

## Стек — не змінювати без узгодження

| Шар | Рішення | Чому саме так |
|---|---|---|
| Хостинг | Один Cloudflare Worker зі static assets | Не Pages. Один деплой на API і фронтенд. |
| API-фреймворк | Hono | Легкий, нативний для Workers. |
| БД | D1 (SQLite) | users, sessions, saved_routes, stations. |
| Кеш | KV | Відповіді Valhalla, геокодування. |
| Маршрути | Valhalla FOSSGIS | Безкоштовний, дає `exclude_tolls` і `has_toll`. |
| Станції | OpenChargeMap → дзеркало в D1 | Прямі виклики на кожен запит заборонені (fair use). |
| Фронтенд | Vite + React + TypeScript | — |
| Мапа | MapLibre GL + OpenFreeMap тайли | Без ключів і лімітів. |

**Заборонено** додавати платні зовнішні API (Chargetrip, Google Maps tiles, TollGuru, TomTom) як основне рішення. Пріоритет проєкту — нульова вартість зовнішніх сервісів. Платний варіант можна лише запропонувати як явно позначений план Б.

## Зовнішні сервіси — жорсткі обмеження

**Valhalla (`https://valhalla1.openstreetmap.de`)**
- Ліміт 1 запит/сек. Усі виклики — **тільки з Worker'а**, ніколи з браузера.
- Обов'язковий заголовок `X-Client-Id: e.car-ua.com`.
- Кожен виклик іде через `src/routing/valhalla.ts` (throttle + KV-кеш). Не робити `fetch` на Valhalla деінде.
- Увесь доступ — за інтерфейсом `RoutingProvider`, щоб роутер можна було замінити локально.

**OpenChargeMap**
- Тільки cron-імпорт у D1 (`src/stations/import.ts`) + точкові запити. Ніколи в гарячому шляху планування.
- Ключ — у секретах Worker'а, не в коді.

## Код

- TypeScript strict. Без `any` — якщо тип невідомий, описати його.
- Ніяких секретів у репозиторії. Тільки `wrangler secret` / `.dev.vars` (у `.gitignore`).
- Паролі — PBKDF2-SHA256 через WebCrypto (`src/auth/password.ts`). scrypt/argon2 у WebCrypto немає, а WASM заради цього не тягнемо. Не міняти на «швидший» хеш.
- Ітерацій рівно **100 000** — це жорстка стеля Workers. Більше рантайм відхиляє помилкою «iteration counts above 100000 are not supported». Кількість ітерацій зберігається в самому хеші, тож стару можна змінити без ламання наявних паролів — але вгору ходу немає.
- Уся бізнес-логіка розрахунків (споживання, крива зарядки, підбір зупинок) — **чисті функції без мережі**, щоб їх можна було тестувати. Мережа ізольована в клієнтах.
- Одиниці вимірювання явні в іменах: `distanceKm`, `energyKwh`, `powerKw`, `durationMin`, `socPct`. Не змішувати.
- Коментарі — тільки там, де пояснюють *чому*, а не *що*.

## Тести

- `npm test` (vitest + `@cloudflare/vitest-pool-workers`) має проходити перед кожним деплоєм.
- Обов'язкове покриття для `consumption.ts`, `charge-curve.ts`, `planner.ts` — детерміновані тести без мережі.
- Не позначати етап у PLAN.md виконаним, якщо тести падають.

## Деплой

- Продакшн: `e.car-ua.com`. Перед прив'язкою домену перевіряти на `*.workers.dev`.
- Міграції D1 — файлами в `migrations/`, застосовувати через `wrangler d1 migrations apply`. Не правити продакшн-схему руками.
